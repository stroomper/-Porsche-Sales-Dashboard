# 🏎️ Dashboard de Vendas Porsche

Dashboard interativa desenvolvida a partir de uma base de dados sanitizada de vendas de veículos Porsche.

O projeto transforma dados de vendas em uma interface analítica e interativa, permitindo explorar informações de faturamento, volume de vendas e outros indicadores por meio de filtros e visualizações dinâmicas.

A dashboard foi desenvolvida com foco em **perguntas de negócio**, evitando apenas apresentar um conjunto de gráficos sem objetivo analítico definido.

## 🎯 Objetivo do Projeto

O objetivo deste projeto é transformar uma base de vendas Porsche em uma **dashboard interativa de análise de dados**, capaz de responder perguntas relevantes sobre o desempenho das vendas.

A solução permite:

* Analisar o volume de vendas;
* Acompanhar a receita;
* Comparar modelos Porsche;
* Analisar o desempenho por cidade;
* Observar a evolução das vendas ao longo dos anos;
* Analisar métodos de pagamento;
* Aplicar filtros aos dados;
* Identificar padrões e diferenças dentro da base.

A proposta é demonstrar como dados tratados podem ser transformados em informações úteis para análise de negócios.

---

## 🧠 Perguntas de Negócio

Em vez de criar gráficos sem uma finalidade definida, a dashboard é estruturada a partir de **três perguntas de negócio**.

As perguntas são selecionadas considerando as dimensões e os indicadores disponíveis na base de dados sanitizada.

Cada pergunta é respondida por meio de um gráfico ou indicador.

As análises podem envolver dimensões como:

* 🚗 Modelos Porsche;
* 📍 Cidades;
* 💰 Receita;
* 📈 Volume de vendas;
* 📅 Ano;
* 💳 Método de pagamento;
* 📊 Valor médio das vendas.

As perguntas finais são definidas de acordo com os dados disponíveis, garantindo que cada visualização tenha uma finalidade analítica clara.

## 📈 Funcionalidades

### Indicadores Principais

A dashboard apresenta indicadores de alto nível, como:

* **Total de Vendas**
* **Receita Total**
* **Valor Médio por Venda**
* Outros indicadores relevantes identificados na base

Os indicadores são atualizados automaticamente de acordo com os filtros selecionados.

### 🔎 Filtros Interativos

É possível realizar análises segmentadas utilizando os campos disponíveis na base, como:

* Modelo;
* Cidade;
* Ano;
* Método de pagamento.

Também existe uma opção para **limpar os filtros** e retornar à visualização completa dos dados.

### 📊 Visualizações Interativas

Os gráficos são escolhidos de acordo com as perguntas de negócio definidas para o projeto.

As visualizações são atualizadas dinamicamente conforme os filtros são aplicados.

## 🗂️ Base de Dados

O projeto utiliza uma base sanitizada contendo **100 registros de vendas**.

A planilha original possui os dados em duas versões:

* Dados originais;
* Dados sanitizados.

Para a construção da dashboard, são utilizados **somente os campos sanitizados**.

A preparação dos dados considera, entre outros aspectos:

* Conversão de preços para valores numéricos;
* Conversão de anos para valores numéricos;
* Padronização dos dados;
* Tratamento dos campos utilizados nas análises;
* Utilização da base como fonte única dos indicadores apresentados.
